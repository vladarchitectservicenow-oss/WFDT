**Self-service data discovery and lineage scanner.**

Author: Vladimir Kapustin  
License: AGPL-3.0-only

---

## What is WFDT?

Workflow Data Fabric introduces data products without lineage visibility.

WFDT scans:
- sys_data_source
- sys_import_set
- sys_metadata_link
- sys_hub_flow_output

Identifies orphaned assets with no parent lineage.
